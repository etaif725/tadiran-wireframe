6. RESOURCES = BLOG
-------------------
/resources
  Blog index and content library

Resources is a blog with custom categories. It is not a separate collection of
unrelated landing-page types.

Content-type categories:
  Reports
  Perspectives / Insights
  Guides
  Case Studies
  Product Updates
  FAQs

Topic categories / tags:
  Deployment
  AI & Analytics
  Resilience
  Industries
  OmniCX

Recommended CMS URL model:
  /resources/{post-slug}
    Individual blog post

  /resources/category/{category-slug}
    Filtered blog category archive

  /resources/topic/{topic-slug}
    Filtered topic archive

The demo currently implements /resources as the routed blog index. Individual
post and category routes are content-model recommendations and are not separate
React routes yet.

Existing demo blog entries:

8. CONTACT INTENT VARIANTS
--------------------------
These use the same /contact page with query parameters.

  Solution inquiry

/contact?intent=industry
  Industry inquiry

/contact?intent=industry&industry={industry-slug}
  Industry inquiry with the selected industry preserved

/contact?intent=demo
  Tailored demo request

/contact?intent=technical
  Technical discussion
